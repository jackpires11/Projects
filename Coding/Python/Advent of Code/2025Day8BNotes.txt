Problem:

Calculate the first 1000 shortest connections in a list of positions. Then, multiply together the sizes of the three largest circuits.

Plan:

-Read in the file into a list of lists of (x, y, z).

-Calculate the distance between each point and every other point; store this in a separate list of lists, [distance, (x, y, z), (x, y, z)]

-Sort the distance list by distance

-Create circuits running through the first 1000 connections in the distance list - Circuits will be a list of coordinates: [(x, y, z), (x, y, z)... ] For each connection, check if either coordinate is already in a circuits; if not, instantiate a new one, if in two, combine, if in one, simply add the missing coordinate.

-Sort the circuit list by size at the end

-Multiply together the size of the first 3 lists in the circuit list.
